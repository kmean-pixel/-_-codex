# 새 세션에 붙여넣을 요청문

내 PC의 Claude Code 로컬 세션에서 이 작업을 처음부터 제대로 다시 진행할 때 사용합니다.

## 사전 준비 (붙여넣기 전에)

1. **유튜브 영상 시청 스킬** 설치 (자막/스크립트 추출 가능한 것)
2. **리서치 스킬** 설치 (웹 검색 + 원문 접근)
3. **원장실 PC에서** Claude Code 실행 (다른 PC에서 하면 실측을 못 함)
4. 이 저장소를 클론해두고, `docs/HANDOVER.md`를 같이 읽히면 리서치 결과를 재활용할 수 있음

---

## 붙여넣을 요청문 (아래 전체를 복사)

```
원장실 PC(Windows)를 주기적으로 스스로 점검·최적화하는 시스템을 처음부터 제대로 구축해줘.
시간이 걸려도 괜찮으니 차분하게, 단계별로 검증하면서 진행해.

■ 1단계 — 유튜브 영상 분석 (영상 시청 스킬 사용)
다음 두 영상을 실제로 시청해서 주장하는 최적화 방법을 하나도 빠뜨리지 말고 항목화해줘.
- https://youtu.be/rat6VoqbsvQ
- https://youtu.be/jt1Mx0alhzo
  (제목: "1분만에 윈도우 최적화로 게임, 작업 효율 200% 향상시키는 4가지 방법!")
각 항목마다 설정 경로, 명령어, 레지스트리 키가 나오면 그대로 기록해줘.

■ 2단계 — 교차검증 리서치 (리서치 스킬 사용)
영상 두 개만 믿지 말고, Microsoft 공식 문서와 오픈소스 프로젝트, 신뢰할 만한 기술 매체를
직접 조사해서 1단계 항목들을 아래 3가지로 분류해줘. 반드시 근거와 출처를 붙여줘.
  (A) 효과 있음 — 해야 하는 것
  (B) 무의미함 — 굳이 안 해도 되는 것
  (C) 위험함 — 하면 안 되는 것
특히 다음은 꼭 검증해줘: 레지스트리 클리너, SSD 조각모음, RAM 클리너,
서드파티 드라이버 업데이터, 서비스 일괄 비활성화, 가상메모리 수동 설정,
Ultimate Performance 전원 계획, 시각 효과 끄기, 빠른 시작(Fast Startup),
원클릭 최적화 프로그램, 디블로트 스크립트(WinUtil / Win11Debloat / O&O ShutUp10).

■ 3단계 — 내 PC 실측
이 PC의 실제 상태를 직접 조사해줘.
Windows 버전·빌드, CPU/RAM, 디스크 종류(SSD/NVMe/HDD)와 여유 공간, SMART 건강 상태,
현재 시작프로그램과 영향도, 현재 부팅 시간, 설치된 앱 전체 목록,
데스크톱/노트북 여부, 그리고 업무용 프로그램(전자차트 등)이 뭐가 깔려 있는지.
→ 실측 결과에 따라 "시각 효과 끄기", "빠른 시작 끄기" 같은 조건부 항목의 답을 정해줘.
→ 의료용 소프트웨어가 있으면 그것과 충돌할 수 있는 최적화는 보류 처리해줘.

■ 4단계 — 점검 항목 카탈로그 설계
1~3단계 결과를 합쳐서 점검 항목을 하나의 데이터 파일(tasks.json)로 정의해줘.
이게 단일 정보원이 되고, 실행 스크립트와 HTML 대시보드가 같은 파일을 읽게 만들어줘.
각 항목은 이렇게 분류해줘.
  - 주기: 주간 / 월간 / 2개월
  - 실행 방식:
      auto   = 스크립트가 끝까지 자동 처리
      semi   = 조사·제안까지만 하고 실제 변경은 내 승인 후 (컨펌 받을 것)
      manual = 물리 작업이거나 판단 필요해서 자동화 불가 (먼지 청소, 외장 백업 연결, BIOS 등)
  - 관리자 권한 필요 여부, 예상 소요 시간, 왜 해야 하는지(근거), 출처

■ 5단계 — 자동화 스크립트 작성
PowerShell로 점검 엔진을 만들고, Windows 작업 스케줄러에 등록하는 설치 스크립트도 같이 만들어줘.
조건:
  - 자동 실행 시간은 19:00 (진료 종료 후). 내 계정은 관리자 권한 있음.
  - PC를 끄고 퇴근할 수 있으니 놓친 작업은 다음 부팅 때 실행되게 StartWhenAvailable 설정.
  - 진료 중에 방해되면 안 되니까 자동 재부팅은 절대 금지.
  - 변경하는 작업 전에는 항상 복원 지점을 먼저 만들어줘.
  - 첫 실행은 드라이런(변경 없이 보고만)으로 확인할 수 있게 해줘.
  - 쓰다 보면 프로그램이 또 새로 깔리니까, 설치된 앱·시작프로그램·예약작업 스냅샷을 저장해두고
    다음 점검 때 "새로 생긴 것"만 찾아서 알려주는 변화 감지 기능을 꼭 넣어줘.
  - 실행이 끝나면 PC 화면에 토스트 알림을 띄우고 HTML 리포트를 남겨줘.
  - 전체를 되돌릴 수 있는 제거 스크립트도 같이 만들어줘.
만들고 끝내지 말고 실제로 한 번 돌려서 정상 동작하는지 검증까지 해줘.

■ 6단계 — 리액티브 HTML 대시보드
점검 항목 전체를 가독성 있게 보여주는 반응형 HTML을 만들어줘.
  - 주기별(주간/월간/2개월) 보기와 자동/반자동/수동 필터
  - "효과 있음 / 무의미 / 위험" 3분류표도 같이 보여줘 (내가 제일 궁금한 부분이야)
  - 각 항목에 왜 해야 하는지 근거와 출처
  - 마지막 실행일과 다음 예정일, 기한 지난 항목은 눈에 띄게
  - 모바일에서도 보기 편하게

■ 7단계 — 예약·알림 시스템
  - 구글 캘린더에 주간/월간/2개월 반복 일정을 등록해줘.
    자동으로 돌아가는 것과 내가 직접 해야 하는 것을 구분해서 제목에 표시하고,
    설명란에 체크리스트를 넣어줘. 알림도 설정해줘.
  - 내가 수동으로 해야 하는 일은 미리 알림을 주고,
    기한이 지났는데 안 했으면 다시 알려주는 재알림까지 만들어줘.
  - Claude 예약 트리거로 주기적으로 리포트를 확인하고,
    필요한 조치를 판단해서 알려주게 연결해줘.

■ 진행 방식
각 단계 끝날 때마다 결과를 보여주고 다음으로 넘어가줘.
내가 결정해야 하는 게 있으면 그때 물어봐.
```
