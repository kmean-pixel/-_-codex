# 원장실 PC 정기 점검·최적화 자동화

원장실 PC(Windows)를 주간/월간/2개월 주기로 스스로 점검·정리하고,
자동으로 되는 것은 자동으로, 관리자 개입이 필요한 것은 미리 알림을 주는 시스템.

## 현재 상태

⏸ **구축 중단 — 사용자 로컬 PC 세션으로 인계**

원격 컨테이너의 네트워크 정책상 YouTube 및 대부분의 외부 참고 사이트 접근이 차단되어,
영상 분석과 원문 교차검증, 실제 PC 실측이 불가능했습니다.
조사한 내용과 설계안을 인계서로 정리했습니다.
