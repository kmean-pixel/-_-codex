# B타워 7층 누수 배상책임 검토

집합건물 7층 임차인(A산부인과)이 시공한 인테리어 수도배관에서 물이 새어 6층과 5층에 피해가 난 사건의
배상책임을 민법, 집합건물법, 판례로 정리한 자료입니다.

> 공개 저장소 보관본이라 병원과 건물 이름은 가명(A산부인과, B타워)으로 바꿨습니다.

## 결론

| 당사자 | 책임 | 근거 |
|---|---|---|
| A산부인과(임차인) | 1차 배상책임 | 민법 제758조 제1항 본문(공작물 점유자) |
| 인테리어 시공업체 | 함께 책임, 구상 대상 | 민법 제750조·제760조, 제758조 제3항 |
| 7층 소유자(임대인) | 원칙적으로 없음(점유자가 면책될 때만 2차) | 민법 제758조 제1항 단서 |
| 관리단·관리인 | 없음 | 집합건물법 제6조 추정 번복 |

전제 사실: 7층은 빈 공실로 임대됐고, 임차인이 수도배관을 포함한 인테리어 전체를 시공했으며,
임차인이 자기 배관에서 샌 것을 인정했습니다. 임대인은 인테리어 공사를 하지 않았습니다.
